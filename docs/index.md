Справочник методов, параметров и событий PumpRoom SDK.
Для первого подключения откройте «Руководство» в верхней панели.

## Выберите задачу

| Что нужно сделать                          | Методы и параметры                                            |
| ------------------------------------------ | ------------------------------------------------------------- |
| Настроить SDK                              | {@link init} и {@link PumpRoomConfig}                         |
| Авторизовать ученика                       | {@link authenticate}, {@link setUser}                         |
| Встроить задание и управлять его загрузкой | {@link mountTask}                                             |
| Получать результат прохождения             | {@link setOnTaskResultChangedCallback}                        |
| Подключить задание к SCORM                 | {@link mountScormTask}, {@link connectScorm}                  |
| Сохранять состояния страницы               | {@link storeStates}, {@link fetchStates}, {@link clearStates} |

## Как пользоваться справочником

Выберите метод в таблице или категорию в боковом меню. На странице метода есть описание параметров,
возвращаемого значения и примеры кода. Поиск в верхней панели помогает найти метод или тип по имени.
В настройках TypeDoc можно выбрать тему оформления.

Подробные пояснения по интеграции и разработке доступны ниже.

## Подключение к своей установке

Для on-premises задайте `apiBaseUrl` и `trustedOrigins` в одном вызове `init()`.
Пример в разделе «Своя установка» руководства подходит для всех способов подключения SDK.
