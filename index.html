Начало работы

1Получите ключ подключения

Перейдите в Админку PumpRoom и выберите пространство, к которому хотите подключиться. В разделе «Интеграция» вы найдёте API-ключ apiKey и идентификатор школы realm.

2Выберите способ подключения

Примеры используют облачные настройки. Для своей установки задайте адрес API и доверенный origin интерфейса вместе: конфигурация on-premises. Загрузка SDK с локального сервера сама по себе не меняет настройки.

Этот способ подойдет вам, если вы используете любую готовую LMS, которая позволяет вставлять на страницу HTML-код.

Добавьте HTML-код на страницу урока:

<script src="__BASE_URL__/bundle/pumproom-sdk-v__MAJOR_VERSION__.umd.js"></script>
<script>
  PumpRoomSdk.init({ apiKey: 'ВАШ_КЛЮЧ', realm: 'ВАШ_ID' });
  PumpRoomSdk.authenticate({
    identity: { provider: 'lms', id: 'ID_СТУДЕНТА' },
  }).catch(console.error);
</script>

Замените значения 'ВАШ_КЛЮЧ' и 'ВАШ_ID' на параметры из админки PumpRoom.

Альтернатива: подключение через ES-модули 
<script type="module">
  import { init, authenticate } from '__BASE_URL__/bundle/pumproom-sdk-v__MAJOR_VERSION__.esm.js';

  init({ apiKey: 'ВАШ_КЛЮЧ', realm: 'ВАШ_ID' });
  authenticate({
    identity: { provider: 'lms', id: 'ID_СТУДЕНТА' },
  }).catch(console.error);
</script>
Как выбрать версию SDK

В примерах используется ветка v__MAJOR_VERSION__. Другие варианты подключения:

  • v__MAJOR_VERSION__ - стабильная версия __MAJOR_VERSION__.x (рекомендуется):
    __BASE_URL__/bundle/pumproom-sdk-v__MAJOR_VERSION__.umd.js
    __BASE_URL__/bundle/pumproom-sdk-v__MAJOR_VERSION__.esm.js
  • latest - последняя версия (сейчас v2):
    __BASE_URL__/bundle/pumproom-sdk-latest.umd.js
    __BASE_URL__/bundle/pumproom-sdk-latest.esm.js
  • v__VERSION__ - конкретная версия (не рекомендуется):
    __BASE_URL__/bundle/pumproom-sdk-v__VERSION__.umd.js
    __BASE_URL__/bundle/pumproom-sdk-v__VERSION__.esm.js

На платформе GetCourse, надо на странице урока добавить в самом начале компонент Блок -> Вставка -> Javascript-код и вставить в него код: 

document.head.appendChild(Object.assign(document.createElement('script'), {
  src: '__BASE_URL__/bundle/pumproom-sdk-v2.umd.js',
  async: true, onload() {
    window.PumpRoomSdk.init({ apiKey: 'ВАШ_КЛЮЧ', realm: 'ВАШ_ID', 'type': 'getcourse' });
    window.PumpRoomSdk.authenticate({ identity: { provider: 'lms', id: '{uid}' } }).catch(console.error);
  }
}));

Замените значения 'ВАШ_КЛЮЧ' и 'ВАШ_ID' на параметры из админки PumpRoom. При встраивании JavaScript-кода включите галочку «Заменять переменные пользователя», чтобы значение {uid} подставлялось корректно.

Если вы хотите интегрировать SDK в проект своей платформы LMS, установите npm-пакет pumproom-sdk : 

npm install pumproom-sdk@__MAJOR_VERSION__

Затем подключите его в свой проект:

import { init, authenticate } from 'pumproom-sdk';

init({ apiKey: 'ВАШ_КЛЮЧ', realm: 'ВАШ_ID' });
authenticate({
    identity: { provider: 'lms', id: 'ID_СТУДЕНТА' },
}).catch(console.error);

Если у вас уже есть сохранённый пользователь, его можно передать напрямую:

import { init, setUser } from 'pumproom-sdk';

init({ apiKey: 'ВАШ_КЛЮЧ', realm: 'ВАШ_ID' });
setUser({ uid: 'UID', token: 'TOKEN' }); // Данные полученные от authenticate()

SDK проверяет источник сообщений от iframe. Если trustedOrigins не указан, разрешены стандартные адреса PumpRoom. Явно заданный список полностью заменяет стандартные адреса. Укажите протокол, домен и при необходимости порт, без пути и масок. Пустой список запрещает сообщения от любых iframe. 

init({
    apiKey: 'ВАШ_КЛЮЧ',
    realm: 'ВАШ_ID',
    trustedOrigins: ['https://tasks.school.example'],
});

Если SCORM-плеер запускает разные SCO по одному адресу, укажите стабильный канонический URL текущего элемента. SDK будет использовать его в API-запросах и ключах локального кеша вместо адреса окна. 

init({
    apiKey: 'ВАШ_КЛЮЧ',
    realm: 'ВАШ_ID',
    pageUrl: 'https://lms.example/scorm/course-42/lesson-1',
});
Как выбрать версию SDK

В примерах используется ветка v__MAJOR_VERSION__. Другие варианты подключения:

  • v__MAJOR_VERSION__ - стабильная версия __MAJOR_VERSION__.x (рекомендуется):
    npm install pumproom-sdk@__MAJOR_VERSION__
  • latest - последняя версия (сейчас v2):
    npm install pumproom-sdk@latest
  • v__VERSION__ - конкретная версия (не рекомендуется):
    npm install pumproom-sdk@__VERSION__

3Добавьте задание на страницу урока

После настройки SDK вставьте задание PumpRoom через iframe. SDK обеспечит авторизацию и обмен данными со встроенным заданием.

Своя установка (on-premises)

Для on-premises установки передайте в одном вызове init() базовый адрес PumpRoom API и доверенный origin интерфейса PumpRoom внутри iframe. API может содержать префикс пути; origin задаётся без пути и не является адресом LMS или SDK. Эта конфигурация применяется к любому способу подключения SDK; для UMD и GetCourse используйте PumpRoomSdk.init(). 

init({
    apiKey: 'ВАШ_КЛЮЧ',
    realm: 'ВАШ_ID',
    apiBaseUrl: 'https://pumproom.school.example/api',
    trustedOrigins: ['https://tasks.school.example'],
});

Функции жизненного цикла

SDK позволяет задавать коллбэки на разные этапы работы с заданием: инициализация, загрузка задания, отправка решения и получение результата. Это дает возможность интегрировать логику вашей LMS с событиями жизненного цикла заданий PumpRoom, например:

  • Сразу обрабатывать и сохранять результат выполнения задачи без запросов на API-бэкенд
  • Последовательно открывать контент урока при выполнении задания
  • Получать идентификаторы задания и его экземпляра
  • Замерять время загрузки и выполнения задания

Подробное описание всех доступных коллбэков и примеры их использования доступны в Технической документации.

История версий

Миграция на v2

Версия v1 больше не получает обновлений и исправлений. Существующие интеграции с закреплённой ссылкой на v1 пока продолжат работать, но для новых подключений и дальнейших обновлений используйте SDK v2. Псевдоним latest теперь указывает на v2.

При переходе замените authenticate({ lms: { id } }) или authenticate({ profile }) на authenticate({ identity: { provider: 'lms', id } }).
